# Google Cloud Platform Notes

A collection of notes about various features of the Google Cloud Platform (GCP), published as a static site via GitHub Pages.

The notes are organised by topic and cover areas such as:

- **BigQuery** – architecture and usage
- **Cloud Logging** – logging features and best practices
- **Time Series & Forecasting** – fundamentals, forecasting options on GCP, and hands-on tutorials with BigQuery ML

The site is available at: https://aurafrizzati.github.io/google-cloud-platform-notes/
